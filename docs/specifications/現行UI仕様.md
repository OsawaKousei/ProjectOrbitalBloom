# 現行UI仕様

この文書は現在のUnreal実装を記録する。MVPの目標仕様や長期企画のUI案とは区別し、変更時は `OrbitalBloomHUD.cpp` と `OrbitalBloomMode.cpp` を確認して更新する。

## 画面構成

- UIは `AHUD::DrawHUD` によるCanvas描画。HUDウィジェットや操作メニューはない。
- 左上に半透明の淡い青白い情報面を置き、タイトル、状態、アンカー名、自機とボスの距離を表示する。
- 右上にSIM経過時間と現在の弾幕パターン名を表示する。
- 画面下部に現在の状態に応じたキーガイドを表示する。
- 空間上にはボスを囲む薄い基準リングを常時描画する。自機の過去軌跡はACTION/TACTICALで直近90 tick、Replayでは記録全体を描画する。
- 診断表示はF3で切り替え、弾数とtickなどを画面下部に追加表示する。F9は診断付きストレス実行の開発用操作。

色はプレイヤー情報・通常マーカーにシアン、危険・配置エラーに赤を使う。外観の方向性は [ビジュアル／UI デザインガイドライン](ビジュアル／UI%20デザインガイドライン.md) を参照。

## 状態別表示と操作

| 状態 | HUD表示 | 操作 |
|---|---|---|
| ACTION | `ACTION / FLOW`、アンカー名と距離、SIM時間、パターン名。被弾後の無敵時間中は中央に赤い `CONTACT` と警告線。再開直後は短時間シアンの画面上下アクセント。 | 矢印キーで現在の移動平面内を2軸移動。XでTACTICALへ。Hで危険弾表示を切替。Rで最初から再開。 |
| TACTICAL | `TACTICAL / CRYSTALLIZE`。接触回数と危険表示ON/OFF、`PLAYER ORBIT` または `BOSS ORBIT` を追加。自機位置に移動平面のリングとグリッド、自機・ボスのラベル、アンカー表示を描く。危険表示ONなら危険弾に赤い菱形と速度線を重ねる。 | XでACTIONへ。右ドラッグでOrbit、VでPlayer/Boss視点切替、ホイールでOrbit距離または配置深度を変更、Hで危険表示切替。CでConverge配置開始／取消、カーソル方向とホイールで位置を調整、左クリックまたはEnterで確定。FでFollowへ戻す。 |
| Converge配置中 | 配置予定地点に菱形マーカー。距離と `CONVERGE` または `OUT OF RANGE` を表示し、自機からのガイド線と到着時の平面リングを描く。下部に配置ガイドを追加。 | カーソル位置で方向を指定、ホイールで奥行き調整、左クリックまたはEnterで確定、Cで取消。 |
| Replay | `REPLAY / FLIGHT`、記録上のアンカー名・距離・SIM時間・パターン名。左側にWIDE/CHASE、再生速度、完了状態を表示。軌跡は初期状態で表示。 | VでWide/Chase切替、Tで軌跡表示切替、Xで1x/0.5x切替、Enterで記録を先頭から再生、Rで新規開始、Escで終了。 |

## 表示上の補足

- `CONTACT` はプレイヤーの被弾後無敵時間に対応し、被弾でプレイは終了しない。
- アンカー名はFOLLOW、CONVERGE、FIXED。ACTION中は現在のアンカーとボスからの距離を表示する。
- 画面下部の操作ガイドは状態別だが、状態固有の全操作を網羅していない。例として配置中の確定／取消ガイドのみは配置中に追加表示する。
- TACTICALは画面の視点・情報を操作するモードで、ゲーム内SIM時間は進まない。
- 表示文字列は英語。ローカライズ切替機能はない。
- 現状はキー割当設定画面、ゲームパッドガイド、ポーズメニュー、設定画面を実装していない。
