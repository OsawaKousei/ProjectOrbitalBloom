# MVPプレイテスト手順

目的はH1〜H4の体験評価。停止回数や被弾数を成績として扱わない。
追加素材・外部サービス・アカウントの準備は不要。UE 5.8.1、キーボード、マウス、
音を確認できる出力環境を用意する。操作はゲーム画面内のガイドを参照。

## 進め方

1. 短い操作練習：矢印キー、Xで停止／再開、Orbit、C→奥行き調整→Enter、Fixed到達、F復帰。
2. Rで通常密度の新規プレイを開始。観察者は正解の通過位置を教えない。
3. 各パターンで気になった形、視点を変えた理由、アンカーを選んだ理由を記録。
   途中で止める回数・時間は自由。必要なら考えを口に出してもらう。
4. 終了後の自動リプレイを鑑賞。Wide / Chaseと軌跡の切替を試す。
5. 別の軌跡でもう一度遊びたいかを聞く。可能ならHで危険表示を切り替えて比較する。
6. プレイ条件・所感と `LogOrbitalBloom` のログを対応付ける。

## 質問と観察

| 仮説 | 質問／観察する事実 |
|---|---|
| H1 観察 | 視点を変えて初めて分かった穴・構造は何か。見づらい箇所はどこか |
| H2 アンカー | 目的地を選んだ理由は何か。現在平面では困り、移動先で理解しやすくなったか |
| H3 実行 | 再開直後に自分で回避する緊張と解放があるか。想定と違った動きは何か |
| H4 リプレイ | 思考時間のない飛行を見たいと思うか。見返したい瞬間と不要な表示は何か |

被弾しても継続できること、TACTICAL中のSIM時刻が変わらないことも確認する。
音は停止中の減衰、再開のアクセント、被弾・確定・到達の識別を聴いて確認する。

## 記録テンプレート

- 日時／ビルド／実行環境／画面サイズ：
- 通常密度、危険表示ON/OFF、操作練習の有無：
- A / B / Cで理解できた構造と分からなかった構造：
- Convergeを選んだ具体的な理由と結果：
- 再開時の操作感／予想外の動き：
- リプレイ視聴・スキップ理由／再挑戦意向：
- 音・画面の読みやすさ／不具合：
- 次の試行で変える最小のパラメータ：

一度に複数の難度・カメラ・速度設定を変えず、理由のある小さな変更で再評価する。
