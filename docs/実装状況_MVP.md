# MVP実装状況

## 実装したプロトタイプ

UE 5.8.1 / Linux。起動マップは `/Game/MVP/Maps/L_MovementStudy`。
75秒のゲーム時間で3種類の弾幕を順に体験し、終了すると停止時間を除いた
リプレイを自動再生する。被弾しても終了しない。

- GameCore：エンジン非依存C++17。120Hz固定ステップ（60Hzもテスト可能）。
- Followの2軸周回、TACTICAL中のConverge配置、到達時のFixed、Follow復帰。
- TACTICAL中はシミュレーションを完全停止。観察・配置は継続できる。
- 弾幕A：斜め方向に穴のある球殻、B：回転する環状トンネル、C：斜めの格子壁。各25秒。
- 連続配列の弾、相対運動による掃引衝突、被弾後0.6秒の無敵、近未来の接近警告。
- UnrealはISMによる一括描画、カメラ、HUD、音響を担当。描画ActorからCoreへの状態逆流はない。
- 1プレイ分の入力・アンカー操作・軌跡をメモリ記録。Coreの再シミュレーションでリプレイする。
- リプレイはWide / Chase、軌跡ON/OFF、等速 / 0.5倍速に対応。
- 実時間、ゲーム時間、停止区間、アンカー操作、被弾、パターン滞在時間、移動距離、リプレイ視聴時間を記録。

リプレイは同一ビルド内の利用を想定する。ファイル保存や異なる環境間の再生互換性は対象外。

## 表現

ユーザー指定のビジュアルガイドラインに合わせ、低情報量の明るいブルーグレー背景、
シアンの自機・操作表示、暖色／マゼンタの弾、警告専用の赤を使用する。
発光コアと色付き外縁、Bloom、自機の残像／軌跡、細線の移動平面とアンカー表示、
ACTION復帰時の短いアクセントを実装した。
音響は合成音によるBGMループ、TACTICAL時の減衰・ローパス、切替／被弾／確定／到達音。

今回作成・変更したバイナリアセット（Editor経由で保存）：

- `Content/MVP/Maps/L_MovementStudy.umap`：検証マップ。
- `Content/MVP/Art/M_Player.uasset`：インスタンス描画への対応。
- `Content/MVP/Art/M_BulletSurface.uasset`：白い発光コアと色付き外縁。
- `Content/MVP/Art/M_Bullet.uasset`：弾用マテリアルインスタンス。

## 操作

| 状態 | 操作 |
|---|---|
| ACTION | WASD：現在の移動平面で2軸移動 |
| ACTION / TACTICAL | Tab / Space：モード切替 |
| TACTICAL | 右ドラッグ／矢印：Orbit、V：Player / Boss中心切替 |
| TACTICAL | ホイール：ズーム、C：Converge配置開始／取消 |
| 配置中 | カーソル：方向、ホイール：奥行き、クリック／Enter：確定 |
| TACTICAL | F：現在の距離を保持してFollow復帰 |
| プレイ中 | H：危険弾表示切替 |
| REPLAY | V：Wide / Chase、T：軌跡、X：等速 / 0.5倍速、Enter：再視聴 |
| 共通 | R：最初からプレイ |
| REPLAY | Escape：終了（PIEではどの状態でもEditorへ戻る） |
| 検証用 | F3：診断表示、F9：通常／約5,000発の負荷モードを切り替えて再開始 |

F9はプレイ内容をリセットするため、第三者テスト中は使用しない。

## 検証と残る評価

- `bash GameCore/test.sh`：移動フレーム、各アンカー、描画周期独立性、停止、
  3弾幕、衝突、無敵、危険推定、75秒進行、入力再生の一致、スロー再生を検証。
- UE Editor Developmentビルド成功。
- 弾マテリアルの親設定が保存されない状態を読み戻しで検出し、修正・保存した。
  保存ログとPIEの白い発光コア／色付き外縁を確認済み。
- Editor再起動後、`OrbitalBloom.Host.InputAndAnchors` が7.22秒で成功。
  W入力、Coreと描画の一致、停止、Converge→Fixed→Followを確認。テストのエラー・警告は0件。
- MCP経由のPIEで停止中の時刻固定、配置・到達・Follow復帰、3弾幕描画、
  75秒終了からの自動リプレイ、カメラ切替とスロー再生を確認。
- PIEでもF9の負荷モードで4,998発の一括表示を確認。
  MCP操作時はEditorのバックグラウンド制限が働くため、この状態のFPSは性能評価に使わない。
- Core負荷テストでは最大4,995発。描画を含むGPU性能や目標FPSの達成を意味しない。
- `LogOrbitalBloom`にCore処理とインスタンス転送の平均CPU時間を出力。
  全フレーム時間・GPU時間は別途Unreal Insights等で評価する。

Editor起動ログにはVulkan bindlessの未使用機能通知と
`r.MotionVectorSimulation` のスレッド安全性警告が残る。後者はエンジン側の
描画検証上の留意点として残している。再起動直後のMCP旧セッションエラーは
再接続後に解消した。最終PIEではゲーム実装・マテリアルの新たなエラーは検出していない。

未完了：第三者によるH1〜H4評価、弾幕の通過難度と視認性の調整、音の聴感確認、
GPU負荷計測、パッケージ化した実行物の検証。
機能が動くことと体験仮説の成立は分けて判断する。

## 検証の再実行

1. プロジェクトをビルドしてEditorで起動する。起動マップは設定済み。
2. PIEを開始し、上記操作でプレイする。75秒は停止時間を含まない。
3. `docs/MVPプレイテスト手順.md`に沿って観察し、出力ログの `LogOrbitalBloom` を保存する。
4. Editor操作の自動テストはSession Frontendの `OrbitalBloom.Host.InputAndAnchors`。
   検証マップを開いてPIEを停止した状態から実行する。
   テストはPIEを開始し、入力・停止・アンカー遷移を確認して終了する。
   テスト登録が更新されない場合はホットリロードだけでなくEditorを再起動する。

既存マップは再生成不要。`Tools/create_movement_study.py` は初期作成用であり、
既存マップを上書きしない。初期作成後のパッケージ解放処理は未再検証。
